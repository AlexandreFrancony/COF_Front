# COF - Site MJ (Frontend)

Frontend React pour l'outil de maître du jeu Chroniques Oubliées Fantasy. Voir [CLAUDE.md](./CLAUDE.md) pour l'architecture détaillée.

## Développement

```bash
npm install
cp .env.example .env
npm run dev
```

Nécessite [COF_Back](https://github.com/AlexandreFrancony/COF_Back) lancé en local sur `:3001`.
